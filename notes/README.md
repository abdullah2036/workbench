# notes/

One file per challenge (`cp template.md <challenge>.md`). This is your team's
shared brain during the event:

- **What's been tried** — kills duplicated effort across teammates and stops AI
  from suggesting the same dead end twice.
- **Key facts from `observe`/`triage`** — ready to paste into AI for candidate
  techniques.
- **Who owns what** — as the generalist/triage person, you route challenges here.

Keep `_work/`, dumps, and challenge binaries OUT of git (see `.gitignore`) — this
folder is just the running log.
